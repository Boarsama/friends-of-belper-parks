## Connect the custom domain to GitHub Pages

1. Buy the domain and retain access to its DNS panel.
2. In the GitHub repository, open **Settings → Pages** and enter `friendsofbelperparks.org.uk` under **Custom domain**.
3. At the domain provider, add the four GitHub Pages `A` records for the root domain:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. Add a `CNAME` record for `www` pointing to `boarsama.github.io`.
5. When GitHub confirms the DNS check, enable **Enforce HTTPS**.

## Verify ownership in Google Search Console

1. Add a new **Domain property** using `friendsofbelperparks.org.uk` (do not include `https://`).
2. Copy the TXT value supplied by Search Console.
3. Add it at the domain provider with host/name `@` and the full value beginning `google-site-verification=`.
4. Keep this TXT record in DNS permanently, then complete verification in Search Console.
5. In Google Play Console, enter `https://friendsofbelperparks.org.uk/` as the organisation website and submit the verification request.
